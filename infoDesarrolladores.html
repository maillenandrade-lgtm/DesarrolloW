Sobre la Aplicación y sus Desarrolladores

Objetivos de la Aplicación

Este proyecto busca desarrollar la interfaz visual de un casino online especializado en ruleta europea, aplicando conceptos de desarrollo web frontend.

Equipo de Desarrollo

Desarrollado por: Vicente Baeza y Maillén Andrade

Tecnologías Utilizadas

Para esta entrega, se ha utilizado HTML5 para la estructura semántica, CSS3 y el framework Bootstrap para los estilos visuales, y JavaScript para la interactividad.

Aclaración Importante: Este es un proyecto académico. No se utiliza dinero real y no se promueve el juego.
